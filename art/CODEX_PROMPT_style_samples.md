## 背景

我在开发一个 macOS 桌面宠物应用（基于开源项目 KuroCat，Tauri + Canvas 2D）。桌宠的主角要换成我家的猫「拿铁」。桌宠的画面构成是：一只猫坐在一个小键盘后面，我敲键盘时它的爪子会跟着拍键，尾巴会摆动。

之前做过几版 AI 形象，问题是：
- 第一版太胖（梨形身体）
- 第二版大头娃娃（头占画面太大，身子像细棍）
- 风格偏「精致甜腻的二次元」，我不喜欢

这一阶段的目标**不是出正式素材**，而是**同一构图、四种不同画风各出一张样稿**，让我挑一个方向。挑完之后会再出完整素材。

拿铁的特征：
- 美国短毛猫，**银色经典虎斑**（银灰底色 + 深炭黑色条纹），两三个月大的小奶猫
- 额头有清晰的「M」纹，眼角有黑色眼线纹延伸到脸颊
- 胸口、下巴偏白，有细小的深色斑点
- 眼睛：偏深的榛绿色/琥珀色，圆
- 鼻子：小，粉棕色
- 耳朵：大、尖，内侧浅粉色
- 尾巴：灰黑相间的环纹，尾尖是实心黑色
- 肉垫：黑色
- 配饰：一个**黄色毛绒甜甜圈形伊丽莎白圈**（分成几段鼓鼓的节，正面打结处垂着两根白色棉绳）

## 构图（四张必须完全一致，方便对比）

- 正面视角，拿铁端坐在一个**小而简单的深色键盘**后面
- 两只前爪搭在键盘上
- 尾巴从身体右侧绕出来，往上翘
- 戴着黄色甜甜圈圈，圈在下巴下方，**不能挡住嘴巴和鼻子**
- 纯色米白背景（`#F7F5F0`），不要场景、不要地面阴影、不要文字
- 正方形，1024 × 1024 px
- 猫 + 键盘大约占画面高度的 75%，居中

## 比例要求（最容易出错，请重点注意）

- **自然的小奶猫比例**，参照 `latte_01_sitting.jpg`
- 头宽约等于身体宽度，或略大一点（头宽 : 身宽 ≈ 1.1 : 1）
- **不要大头娃娃**（头不要超过画面宽度的 45%）
- **不要胖**（身体不要是梨形、保龄球形）
- 脖子自然过渡，不要细成一根棍

## 表情与气质

- 整体方向：**诙谐、有点呆、有点面瘫**，像表情包里那种一本正经的猫
- **不要**：闪亮大眼睛、星星眼、腮红泛滥、甜腻卖萌的二次元风格
- 可以可爱，但要「好笑的可爱」，不是「精致的可爱」

## 四种画风

### A · 手绘涂鸦表情包
- 随性、略带抖动但自信的手绘墨线，像中文表情包/涂鸦漫画
- 平涂颜色，几乎不做渐变阴影，形状简化
- 表情：半睁眼的嫌弃脸 / 无语脸，小嘴

### B · 扁平矢量贴纸
- 干净均匀的圆润描边，平涂 + 一层柔和的赛璐珞阴影
- 虎斑条纹几何化、简化
- 表情：豆豆眼，带点得意或犯傻
- 参考气质：LINE 贴纸、现代 App 吉祥物

### C · 绘本厚涂
- 温暖的儿童绘本插画，水粉/彩铅质感，能看到轻微笔触和纸张颗粒
- 毛色接近真实但做了简化，光线温暖
- 表情：圆眼睛 + 一点点皱眉，一脸严肃地盯着你（严肃到好笑）

### D · 像素风
- 复古 16-bit 像素画，约 64 × 64 像素网格放大，硬边、不要抗锯齿模糊
- 有限色板，可用少量抖动（dithering）做明暗
- 表情：面瘫、略带得意
